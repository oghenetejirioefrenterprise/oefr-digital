# Product Playbook

## How We Ship

### Philosophy
- **80% distribution, 20% building** — the bottleneck is demand, not supply
- **Build what sells, not what you know** — market research drives product decisions
- **Ship fast, iterate faster** — a launched product beats a perfect prototype

### Build Pipeline
1. **Research** — Scan Reddit, X, TikTok, Product Hunt, Gumroad trending, Indie Hackers
2. **Validate** — Is this something people are BUYING? Not just discussing.
3. **Build** — Spawn dev subagent with clear spec + validation contract
4. **QA** — Neo security audit + Trinity delivery verification
5. **Deploy** — Vercel prod + Stripe keys + Gumroad listing
6. **Distribute** — X thread, Reddit value post, Pinterest pin, directory submissions

### Delivery Checklist (MANDATORY)
Before ANY product is marked "done":
- [ ] Landing page live and loads correctly
- [ ] Stripe checkout completes (or Gumroad purchase works)
- [ ] Product files exist OR web app is fully functional
- [ ] Delivery mechanism verified end-to-end
- [ ] Neo security sign-off

### Factory AI Methodology
1. **Validation Contract First** — Define tests BEFORE code. Tests ARE the spec.
2. **Feature Decomposition** — One feature per subagent, clean context window.
3. **Milestone Validation** — Build/test/lint after each feature group.
4. **Model Role Separation** — Opus plans, Sonnet implements.
5. **Test-Driven AI Dev** — More tests at end than at start.

### Pricing Strategy
- Digital downloads: $9–$59 range
- Web apps: $19–$37 (one-time unlock)
- AI prompt packs: $19 (90-98% margin)
- Lead magnets: FREE (email capture → upsell)
- Launch discounts: LAUNCH50 = 50% off

### Product Categories
1. **Network Engineering** — TJ's domain expertise (templates, checklists, automation)
2. **Productivity Apps** — Web-based tools (budgets, invoices, habits)
3. **AI Prompt Packs** — Trend-driven, highest margin (current focus)
4. **Future:** Whatever the market demands next
